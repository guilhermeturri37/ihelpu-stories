# iHelpU — Stories do Marketplace

Artes dos Stories publicados automaticamente no [@ihelpuoficial](https://instagram.com/ihelpuoficial)
com aparelhos do [marketplace de seminovos](https://seminovos.ihelpu.com.br).

Repositório público porque a API do Instagram busca a imagem por URL, sem autenticação.
As artes contêm apenas dados já públicos no site: modelo, preço e a foto do próprio anúncio.
Nome do vendedor é deliberadamente excluído.
